# FIF 智慧教学平台全自动刷课助手

适用于 `icourse.fifedu.com` 的 Tampermonkey（油猴）用户脚本，当前版本：**1.7.0**。

> 请仅在自己有权使用的账号和课程中，按学校及平台规则使用。自动化操作可能产生学习记录或触发平台风控，使用前请自行评估风险；本脚本不承诺规避平台检测，也不保证在所有课程和页面版本中均可运行。

**免责声明：使用本脚本即代表你已完整阅读并充分知悉所有风险（包括但不限于学习记录异常、风控识别、成绩作废、账号受限等），任何因使用本脚本产生的一切后果均由使用者本人承担，与脚本制作者无关。本脚本仅供个人研究、学习与技术交流使用，严禁用于违反校规校纪、平台协议或法律法规的场景。**

## ⚠ 高风险功能（务必先读）

脚本面板中已把高风险项单独放入红色 **「高风险功能」** 栏目，请与普通功能区分开对待。

| 功能 | 风险等级 | 原因与建议 |
| --- | --- | --- |
| **极速秒刷模式** | **高** | 不实际观看，直接调用平台 Vue 底层进度接口把视频/文档/PPT 上报为 **100% 完成**。学习进度与学习时长严重不符，是最典型、最容易被平台风控或审计识别的异常行为，可能导致学习记录作废、成绩无效、账号被限制。**该选项历史默认开启，担心风险请立即关闭**，改用「视频常规播放倍速」。 |
| AI 自动答题（练习/测评） | 中 | 题目并非本人作答，且答案来源（平台接口/AI）都可能出错。请抽查正确率，不要把 AI 成绩当作真实水平。 |
| 循环测试（未达目标自动再测） | 中 | 会在短时间内连续发起多轮完整测评。平台对测评有最短时间间隔限制，脚本遇到间隔/无题提示会停止，并设有 **20 轮上限**；请设置合理目标，避免长时间无人值守循环。 |
| 多课程连刷 | 低（本身不属高风险） | 实现上只是自动点击课程卡片、展开课程列表进行跳转，**不伪造任何学习数据**，因此未列入高风险栏目。但它会让上述功能在所有课程上无人值守连续执行，**放大其他功能的风险**，只刷一门课时请保持关闭。 |
| 跳过单元检测 | 视课程而定 | 可能跳过必做测验，直接影响成绩，请按课程要求选择。 |

再次强调：**没有任何方式可以保证不被平台检测**。如果课程成绩、学分或考核对你很重要，请不要开启「极速秒刷模式」。

## 功能

- 识别学习空间中的课程，自动巡航课程章节。
- 视频自动倍速播放；极速模式（高风险）下尝试直接完成视频、文档和 PPT 学习进度。
- PPT 自动翻页，Word/PDF 文档自动定位到末页。
- 自动进入自适应练习，逐题选择答案、提交并打开练习报告。
- 支持课程首页「测评评估掌握度」自动刷题：首次进入自动校验并补全测评入口，自动完成「更改学习目标 → 全选 → 确定 → 开始测评」，逐题作答并关闭报告。
- 测评支持 **循环测试**：可设置目标熟练度指标（选填，0-100 整数），本次未达目标自动开始新一轮完整测评，达标、手动停止或出现异常即终止。
- 练习答案优先使用平台接口中已经返回的数据；缺失时可调用 DeepSeek 等 OpenAI 兼容接口兜底。
- 遇到「重新练题」「提升掌握度」等入口时自动重试；仍无题目则返回目录继续学习。
- 支持多课程连刷、跳过单元检测、异常小节跳过缓存和运行日志。
- 无可靠答案时暂停当前练习，不随机提交答案。

## 〇、AI API Key 获取方式

本脚本的 AI 自动答题依赖 **DeepSeek 开放平台 API**。脚本不内置任何 Key，需要自行申请：

1. 打开 DeepSeek 开放平台：<https://platform.deepseek.com/>
2. 使用邮箱（推荐）或 GitHub 账号注册，完成实名/企业认证（具体要求以平台当前规则为准）。
3. 登录后进入 **API Key 管理** 页面，点击 **创建 API Key**，为脚本用途起一个便于识别的名字（如 `fif-helper`）。
4. 创建成功后，系统只会显示一次完整 Key，请立即复制并妥善保存；Key 丢失无法找回，只能重新创建。
5. 充值：DeepSeek API 按量计费，新注册通常有免费额度，后续可在控制台充值。

⚠ **安全提醒**：
- API Key 等同于密码，**绝对不要** 写进脚本后上传公开仓库、发给他人或贴到聊天群。
- 脚本配置面板会将 Key 保存在当前浏览器的 Tampermonkey 存储里，仅限本机使用。
- 如怀疑 Key 已泄露，立即到 DeepSeek 控制台删除旧 Key 并创建新的。

## 一、安装环境

推荐使用 **Microsoft Edge** 或 **Google Chrome**。

1. 从浏览器扩展商店安装 **Tampermonkey（篡改猴）**。
2. 在浏览器扩展管理页确认 Tampermonkey 已启用。
3. 建议同时启用 Tampermonkey 的「允许访问文件 URL」，便于从本地文件安装。

脚本只匹配以下平台及其课件预览域名：

- `https://icourse.fifedu.com/*`
- `https://resc.fifedu.com/iplat-resc/pdfv-resource/web/viewer.html*`
- `https://*.ow365.cn/*`

## 二、安装脚本

### 方法 A：从 GitHub 安装（推荐）

1. 在本仓库打开 [`course-learning-toolkit.user.js`](./course-learning-toolkit.user.js) 文件页面，点击右上角 **⬇️ Download** 按钮下载脚本到本地。
2. 也可以直接打开 [油猴脚本安装地址](https://raw.githubusercontent.com/XiaoMaxer/course-learning-toolkit/main/course-learning-toolkit.user.js)，Tampermonkey 会自动弹出用户脚本安装页。
3. 核对脚本名称、版本和匹配网站后，点击 **安装**。

### 方法 B：本地文件安装

1. 下载或克隆本仓库，确认脚本扩展名为 `.user.js`，不要改成 `.txt`。
2. 在 Tampermonkey 扩展详情中开启「允许访问文件 URL」。
3. 将 `course-learning-toolkit.user.js` 拖入 Edge 窗口，或在地址栏打开它的 `file:///` 地址。
4. 在 Tampermonkey 安装页点击 **安装**。

如果浏览器只显示源码而没有弹出安装页，可在 Tampermonkey 管理面板中新建脚本，将文件全部内容粘贴进去并保存。

## 三、配置 AI 自动答题

脚本不预置任何 API Key。需要 AI 兜底答题时，请先按「〇、AI API Key 获取方式」申请 DeepSeek API Key，再回到本节配置。

1. 手动登录 FIF 智慧教学平台，进入学习空间或课程学习页。
2. 在页面右侧的「FIF全自动刷课助手」面板中找到 **AI 自动答题（DeepSeek）**。
3. 勾选 **启用**，并填写以下配置：

| 配置项 | 建议值或说明 |
| --- | --- |
| DeepSeek API Key | 你自己的 Key，输入框失去焦点后保存 |
| 模型名称 | `deepseek-chat` |
| 接口地址 | `https://api.deepseek.com/chat/completions` |
| 答题提示词 | 一般保持默认；要求模型严格返回答案 JSON |
| 思考延迟 | 默认 `2500 ~ 6000 ms`，不建议设为过高频率 |
| 单次练习题目上限 | 默认 `50`，可按课程情况调整 |

5. 点击 **测试 API**。测试通过后再启动自动刷课。
6. 勾选 **自动完成练习**。

API Key 保存在当前浏览器的油猴脚本存储及本地存储中，不会随本仓库上传。请勿把自己的 Key、账号或密码写进脚本后公开分享。

## 四、开始刷课

1. 在浏览器中手动登录平台。脚本不会也不需要保存账号密码。
2. 进入学习空间，确认页面已显示助手脚本面板。
3. 按需选择：
   - **极速秒刷模式（高风险）**：位于红色「高风险功能」栏目，**历史默认开启**。它会不观看直接上报 100% 进度，并非普通加速播放；担心风控、成绩或账号风险时请立即关闭，改用常规倍速。
   - **视频常规播放倍速**：关闭极速模式时使用，默认 4 倍速。
   - **自动完成练习**：自动进入并完成自适应练习。
   - **跳过单元检测**：默认开启；如需处理检测，请关闭。
   - **多课程连刷**：当前课程结束后自动返回学习空间并进入下一门课。它本身不伪造学习数据，但会放大其他功能无人值守连续执行的风险。
4. 点击 **开始全自动刷课**。
5. 通过面板状态和日志查看当前进度。需要停止时点击 **暂停自动刷课**，不要仅关闭面板。

如果只需要刷当前一门课，请保持「多课程连刷」关闭。

## 五、练习答题流程

进入自适应练习后，脚本会自动处理：

1. 识别「开始练习」「继续练习」「提升掌握度」「重新练习」等入口。
2. 等待题干和选项加载完成。
3. 优先读取平台练习响应中可用的答案；无法取得时再按配置调用 AI。
4. 点击对应选项，等待随机思考延迟后点击「选完了」。
5. 多题练习中自动进入下一题，全部完成后点击「显示报告/查看报告」。
6. 如果出现「重新练题」，最多自动重试两次；仍没有有效题目则返回课程目录。

脚本无法获得可靠答案时会暂停当前练习并记录日志，请手动检查，不要强行连续刷新页面。

### 测评评估掌握度

课程首页右侧掌握度卡片会显示「测评评估掌握度 >」入口。进入课程首页后：

1. 如需连续测评，先在「测评评估掌握度」区域勾选 **循环测试**，并选填 **目标熟练度指标**（0-100 的整数，输入时实时校验）。目标留空时，即使打开循环开关也只执行单轮；输入非法目标会拒绝启动。
2. 点击面板底部 **🎯 测评评估掌握度（自动答题）**，或从 Tampermonkey 菜单执行同名命令。运行中按钮会变为 **⏹ 停止测评**，点击后请求手动终止。
3. 脚本自动打开测评弹窗，校验并补全测评入口及学习目标，再点击「开始测评」。
4. 题目优先使用平台接口返回的答案；缺失时调用已配置的 AI。
5. 全部答完后自动点击「显示报告」，读取报告摘要及当前熟练度，并关闭报告。
6. 已启用循环且填写合法目标时，本轮熟练度低于目标会自动开始下一轮完整测评；达到或超过目标、手动停止、单轮未完成、熟练度读取失败或出现异常时终止。循环最多执行 **20 轮**，不会无限重试。

平台对测评有最短时间间隔限制。如果提示「距离上一次测评时间过短」「暂无可测评题目」或知识点已掌握，脚本会记录提示并停止，不会强行重复提交。**循环测试会在短时间内连续发起测评并自动作答，请设置合理目标，避免长时间无人值守运行。**

## 六、更新脚本

1. 在仓库页面打开新版 `.user.js` 文件，点击右上角 **⬇️ Download** 下载。
2. 在 Tampermonkey 管理页点击 **更新**（或重新安装下载的新版本）。
3. 更新后刷新 FIF 平台页面。

维护者修改脚本时应递增头部 `@version`，否则 Tampermonkey 可能把重新安装识别为同版本覆盖。

如果弹出「即将重新安装用户脚本」或「即将重置所有脚本的设置」：

- 只是想保留现有配置时，点击 **取消**，确认版本号后再更新。
- 不要在未核对提示的情况下确认重置，以免丢失面板配置和跳过记录。

若浏览器询问「是否离开网站？」，根据实际情况选择「离开」后继续安装或更新。

## 七、常见问题

### 页面没有显示助手面板

- 确认 Tampermonkey 和本脚本均已启用。
- 确认当前网址是 `https://icourse.fifedu.com/...`，然后刷新页面。
- 检查是否安装了其他会修改同一页面的脚本，可暂时停用后重试。

### 日志提示未配置 API Key

在 AI 设置中填写 Key，点击输入框外部使其保存，再点击「测试 API」。如果不需要 AI，可关闭「AI 自动答题」；但没有平台答案数据时，练习可能无法自动完成。

### 练习报告显示 0/1、正确率 0% 或直接出现「重新练题」

部分课程活动的题库本身为空，平台的 `questionApi/next` 接口会直接返回无效题号并生成空报告。这不是 AI 答错。脚本会有限次重试，仍为空时跳过该活动并继续其他小节。

### 某小节反复进入或之前被异常跳过

点击面板的 **清空跳过缓存**，然后重新启动。清空后脚本会重新访问此前因异常而跳过的小节。

### 视频、PPT 或文档没有完成

先关闭「极速秒刷模式」，刷新页面后重试该小节。课件预览由第三方域名提供，平台或预览器页面结构更新后可能需要同步更新脚本。

### 如何立即停止

点击面板的 **暂停自动刷课**。若页面正在跳转或请求尚未结束，可再关闭当前课程标签页。
